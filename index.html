🌐 DHCP – IP-Adressen auf Autopilot

Wie bekommt dein Handy im WLAN eigentlich seine IP-Adresse, obwohl du nichts eintippst?

💡 Was ist DHCP?

DHCP steht für Dynamic Host Configuration Protocol. Ein DHCP-Server kann Clients automatisch mit wichtigen Netzwerkeinstellungen versorgen.

🎯 Warum ist das praktisch?

Viele Geräte lassen sich schnell konfigurieren. Tippfehler und doppelt vergebene IP-Adressen werden leichter vermieden.

🔄 Der DHCP-Ablauf – DORA

1 · DiscoverDer Client sucht einen DHCP-Server.
2 · OfferDer Server bietet eine freie IP-Konfiguration an.
3 · RequestDer Client fordert das Angebot an.
4 · AcknowledgementDer Server bestätigt die Vergabe.

🧠 Diese Begriffe solltest du kennen

AdressbereichBereich, aus dem der DHCP-Server IP-Adressen vergeben darf.
NetzmaskeLegt fest, welcher Teil der IP-Adresse zum Netzwerk gehört.
Standard-GatewayAdresse des Geräts, über das andere Netzwerke erreicht werden können.
DNS-ServerHilft dabei, Namen wie Webseitenadressen einer IP-Adresse zuzuordnen.
Lease TimeZeitspanne, für die eine IP-Konfiguration einem Client zugewiesen wird.
🧪 FILIUS-Mission
Richte einen DHCP-Server mit einem passenden Adressbereich ein. Stelle die Clients auf automatische IP-Konfiguration und prüfe anschließend mit der Befehlszeile und ping, ob die Verbindung funktioniert.
